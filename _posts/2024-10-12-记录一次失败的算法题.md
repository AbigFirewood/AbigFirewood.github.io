## 2024年10月12日 403. 青蛙过河
[题目链接](https://leetcode.cn/problems/frog-jump/description/?envType=study-plan-v2&envId=2024-spring-sprint-100)
一只青蛙想要过河。 假定河流被等分为若干个单元格，并且在每一个单元格内都有可能放有一块石子（也有可能没有）。 青蛙可以跳上石子，但是不可以跳入水中。

给你石子的位置列表 stones（用单元格序号 升序 表示）， 请判定青蛙能否成功过河（即能否在最后一步跳至最后一块石子上）。开始时， 青蛙默认已站在第一块石子上，并可以假定它第一步只能跳跃 1 个单位（即只能从单元格 1 跳至单元格 2 ）。

如果青蛙上一步跳跃了 k 个单位，那么它接下来的跳跃距离只能选择为 k - 1、k 或 k + 1 个单位。 另请注意，青蛙只能向前方（终点的方向）跳跃。
### 我的思考
1. 有两个影响因素： 一个是跳跃长度 一个是位置
2.  dp要求的是可达性，是bool类型
3.  有 bool dp [i][n] 表示：在i位置，之前跳跃了j步 是否可达
4. 可以写出状态转移方程：
```c++
dp[i][j] = dp[i-j][j-1] || dp[i-j][j-1] || dp[i-j][j-1]
```
5. 初始化条件：dp[stones[0]][0] = true 表示在起始位置跳跃0步
得到如下的代码：
```c++
class Solution {
public:
    bool canCross(vector<int>& stones) {
        int max_size = stones[stones.size()-1];
        int little = stones[0];
        if(stones[1]-stones[0]!= 1)
           return false;
        vector<bool>flag(max_size+1,false);
        for(int  i=0;i<stones.size();++i){
            flag[stones[i]] = true;
        }
        for(int i=0;i<max_size+1;++i){
            for(long j=0;j<max_size+1;++j){
                dp[i][j] = false;
            }
        }
        vector<vector<bool>> dp(max_size+1,vector<bool>(max_size+1,false)); 
        //dp[1][1] = true; dp[0][0] = true;
        dp[stones[1]][1] = true;
        dp[stones[0]][0] = true;
        for(long i=2;i<max_size+1;++i){
            for(long j=1;j<i;++j){
                dp[i][j] = flag[i]&&(dp[i-j][j-1]||dp[i-j][j+1]||dp[i-j][j]);
            }
        }
        bool f = false;
        for(long i=0;i<max_size+1;++i){
             f = dp[max_size][i]||f;
        }
        return f;
    }
};
```
结果发现竟然爆栈了！因为测试用例的数据太大：{0,1,2147483647} 超过了vector能够承受的量 甚至换成数组也不行 而且dp数组存储的无用信息太多
### 题解的解法
题解的方法也是dp 也是一个表示跳跃次数 一个表示位置 但是题目有如下的改进：
1. 我的dp[i][j]中，i表示的是数轴上的位置 而题目中i表示的是stones数组的坐标（因为青蛙也只能跳到石头上） 这样dp数组就压缩了! 
2. 通过推断发现，dp数组的第二维度也可以是stones数组的长度！推断过程如下：
* [x] 青蛙只能跳到石头上 跳到stones数组第i个石头上的时候，他最多跳跃i步
* [x] 每跳跃一次，最多增加1单位的距离，而初始距离是1
* [x] 因此跳跃到i的时候，青蛙最多继续跳跃的距离是i+1
这样就用dp[n][n]来表示动态规划数组，节省了大量的内存
```c++
class Solution {
public:
    bool canCross(vector<int>& stones) {
        int n = stones.size();
        vector<vector<int>> dp(n, vector<int>(n));
        dp[0][0] = true;
        for (int i = 1; i < n; ++i) {
            if (stones[i] - stones[i - 1] > i) {
                return false;                          //筛掉了不正常的情况
            }
        }
        for (int i = 1; i < n; ++i) {
            for (int j = i - 1; j >= 0; --j) {        //遍历所有可能的j（j表示i的上一个）
                int k = stones[i] - stones[j];        //计算跳跃距离
                if (k > j + 1) {                      //跳跃距离不可能超过j+1
                    break;
                }
                dp[i][k] = dp[j][k - 1] || dp[j][k] || dp[j][k + 1]; //如果在j有如下的一个是true 那么i就是可达的
                if (i == n - 1 && dp[i][k]) {
                    return true;
                }
            }
        }
        return false;
    }
};
```
